# Fractals

## Requirements
- Python 3.9 or later.
- A dedicated graphics card (AMD, NVIDIA) or a recent integrated chip.

## Installation

### On Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### On Windows

```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Launch the app

```bash
python main.py
```
