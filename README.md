# Fractals

![Language](https://img.shields.io/badge/Language-Python-ffdd63)
![Size](https://img.shields.io/badge/Size-22,5Kio-f12222)
![Open Source](https://badges.frapsoft.com/os/v2/open-source.svg?v=103)

A simple fractal generator, capable of displaying the Julia set or the Mandelbrot set.

## Requirements
- Python 3.9 or later.
- A dedicated graphics card (AMD, NVIDIA) or a recent integrated chip.

## Installation

### On Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### On Windows

```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Launch the app

```bash
python main.py
```
